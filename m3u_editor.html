Sobre la validación de enlaces: por seguridad, los navegadores no dejan que una página web lea el código de respuesta real de otro servidor (política CORS), así que esta herramienta interpreta “vivo” como “el navegador logró establecer conexión” y “muerto” como “la conexión falló directamente” (DNS, servidor caído, timeout). Streams http:// cargados desde esta página https:// pueden marcarse como muertos por bloqueo de contenido mixto aunque estén funcionando. Para una validación más exacta con códigos HTTP reales, usá el script de escritorio (m3u_manager.py).
Sobre los botones de TMDB: buscan cada título en The Movie Database y completan el tvg-logo con el póster oficial y/o el group-title con el género principal (película o serie). Funciona mejor con títulos "limpios" (sin etiquetas de calidad tipo HD/4K) — podés editar el título en la tabla antes de buscar si el resultado no es el esperado. Canales de TV en vivo, radios o eventos deportivos normalmente no tienen ficha en TMDB, así que quedarán sin resultado.
